# AEON PPM Training System

Frontend GitHub Pages.

Fitur:
- Search NIK
- Search Nama
- Dropdown autocomplete
- Menampilkan section
- Menampilkan current level
- Menampilkan basic wajib
- Link modul training

Setup:

1. Upload file ke GitHub.
2. Edit app.js.
3. Ganti URL_APPSCRIPT_ANDA dengan URL Web App Apps Script.
4. Aktifkan GitHub Pages.
